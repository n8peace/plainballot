# Security

## Reporting a problem

Please don't open a public issue for a security problem. Use **[Report a vulnerability](https://github.com/n8peace/plainballot/security/advisories/new)** on this repository's Security tab, or message [@n8peace](https://x.com/n8peace) on X. You'll get a reply within 3 days.

Especially useful to hear about:

- A way to change what voters see without a pull request (for example, tricking the "Not right?" recheck into publishing a false claim).
- A way to run up the AI bill or get around the rate limits.
- Instructions hidden in a web page or a voter's text that change how a model behaves.
- Leaked keys or personal data.

## What's in place

The layers that protect the site and its spending are described in [docs/security.md](docs/security.md). Plain Ballot stores no accounts and no addresses.
